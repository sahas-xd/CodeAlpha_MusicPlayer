# Loopify

Loopify is an anime-inspired music player built with HTML, CSS, and JavaScript. It features an elegant night-sky theme, Japanese text, and animated geometric song covers.

## Features

- Three original instrumental demo tracks generated in the browser
- Play, pause, previous, and next controls
- Track progress and volume controls
- Playlist with autoplay
- Add audio files from your device
- Animated landing section and song covers
- Responsive layout for desktop and mobile
- Reduced-motion support

## Run Loopify

1. Download or clone this repository.
2. Open `Loopify.html` in a modern web browser.
3. Click **Play** to start a demo track.
4. Click **Add tracks** to choose audio files from your device.

The demo tracks are generated locally in your browser. You do not need a separate media folder or an internet connection to play them.
